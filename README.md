# GitHub Pages Dashboard Template

This is a static multi-page HTML dashboard template designed for GitHub Pages.

## Files

- `index.html` — Overview page
- `Lucas Growth Plan.html` — Power tab
- `gas.html` — Gas tab
- `load.html` — Load tab
- `curves.html` — Curves tab
- `assets/style.css` — Shared styling
- `assets/script.js` — Shared mobile navigation behavior

## How to use

1. Create a GitHub repository.
2. Upload these files to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and root folder.
6. Your dashboard should publish at `https://yourusername.github.io/repository-name/`.

## How to customize

To add your own content, edit the body of each page inside:

```html
<main class="main-content">
  ...
</main>
```

Keep the sidebar and shared asset links if you want the navigation and design to stay consistent.
